# FRIES-Rack-Planner - 籃具工件最佳擺放 3D 展示

這份 HTML 程式碼是一個全功能、基於 WebGL (Three.js) 與 Tailwind CSS 開發的 **「3D 智慧籃具工件裝箱與隔板總成計算器」**。

以下是該網頁的功能結構與詳細操作使用說明：

---

## 🛠️ 主要功能亮點

1. **3D 即時動態渲染**：可在畫面上直觀預覽塑膠籃、不鏽鋼外籃、內部交錯隔板以及工件的排布狀態。
2. **多角度與姿態搜尋**：支援 6 種正交翻轉姿態，並可開啟任意角度（0°~90°）的 Yaw 旋轉搜尋最佳空間利用率。
3. **內部交錯隔板連動**：支援自訂網格數量與 Pitch 間距，並可切換「啟用/關閉內部隔板」。
4. **雙重籃具堆疊評估**：自動計算塑膠籃在不鏽鋼外籃中的最大堆疊層數與頂部預留高度。
5. **報告匯出**：可一鍵將當前的尺寸與最佳裝箱計算結果匯出為 `.txt` 文字報告。

---

## 📖 操作使用說明

網頁介面主要分為 **左側控制面板**（參數設定與比較表）與 **右側 3D 視覺化畫布**（即時結果展示）。

### 1. 基礎設定與工件尺寸 (Left Panel - Top)

* **單位選擇**：下拉選單可切換 `毫米 (mm)`、`公分 (cm)` 或 `英寸 (inch)`。
* **工件間隙 (Gap)**：設定工件與工件之間、以及工件與隔板/籃壁之間的最小安全距離（預設為 1 mm）。
* **任意角度旋轉 (Arbitrary Yaw Rotation)**：
* **關閉**：僅評估工件的 6 種正交放置姿態。
* **開啟**：提供「智慧優化搜尋（以 2° 步幅測試 0°~90°）」或「指定固定角度」。


* **工件尺寸 (Workpiece)**：輸入單個工件的長 (L / X軸)、寬 (W / Z軸)、高 (H / Y軸)。

---

### 2. 籃具空間與硬體網格設定 (Middle Left Panel)

* **啟用內部交錯隔板**：
* **勾選開啟**：工件會嚴格限制在隔板網格內，並考慮隔板厚度（`partitionThickness`）。
* **取消勾選**：工件直接在塑膠籃淨空間內以固定 Gap 均勻陣列。


* **網格與容納空間連動**：
* 輸入長向格數 (X) 與間距 (Pitch L)、寬向格數 (Z) 與間距 (Pitch W)。
* **容納長 (L)** 與 **容納寬 (W)** 會自動計算連動（容納長 = 格數 X 間距）。


* **塑膠籃結構與外框參數**：
* 設定牆面單邊加厚、底板厚度與底板網格線厚度，系統會自動算出塑膠籃外框總尺寸 ($L \times W \times H$)。



---

### 3. 不鏽鋼外籃與堆疊總成設定 (Bottom Left Panel)

* **快速選用標準不鏽鋼籃**：提供 `#1 標準`、`#2 大型`、`#3 小型` 等預設選單。
* **自動計算堆疊層數**：
* 勾選「依不鏽鋼籃自動計算層數」後，系統會依據不鏽鋼籃內部容納高度與頂部預留高度（預設 36 mm），自動算出**最多可堆疊幾層塑膠籃**。


* **裝載評估結果**：底部卡片會顯示「✓ 可完全容納」或「✗ 尺寸超出限制」並提示理由。

---

### 4. 3D 視覺化畫布操作 (Right Panel)

* **視角操作**：
* **旋轉視角**：按住 **滑鼠左鍵** 並拖曳。
* **平移視角**：按住 **滑鼠右鍵** 並拖曳。
* **縮放畫面**：滾動 **滑鼠滾輪**。


* **工件半透明切換**：點擊畫布右上角的 `👁️ 工件半透明` 按鈕，可切換工件透明度，以便透視觀察內部的隔板與結構。
* **頂部數據卡片**：即時顯示「總裝箱數量」、「空間利用率」、「最佳放置姿態」與「旋轉角度 / 層數」。

---

### 5. 比較表與報告匯出

* **姿勢變體詳細比較表**：
* 列表呈現所有可採行的姿態、旋轉角度與單層數量。
* **點擊表格中任意一列**，3D 畫布會即時切換顯示該方案的擺放效果。


* **匯出計算報告**：點擊頁面右上方「匯出計算報告」按鈕，即可將目前參數與最佳擺放數據下載為文字檔。
